# Arquivos Oficiais de Marca — MOVI

Este diretório está preparado para receber os arquivos oficiais da marca MOVI:
- `logo-full.svg` / `logo-full.png`
- `logo-horizontal.svg` / `logo-horizontal.png`
- `logo-graphite.svg` / `logo-graphite.png`
- `logo-white.svg` / `logo-white.png`
- `symbol.svg` / `symbol.png`

O componente `<MoviLogo />` (`src/components/brand/MoviLogo.tsx`) e `<MoviSymbol />` detectam e renderizam as variantes oficiais em vetor responsivo e possuem suporte para carregar arquivos adicionados a esta pasta sem necessidade de refatoração de código.
